# school76

Платформа совместной разработки образовательного кубсата формата 1U: управление задачами по подсистемам, встроенный технический чат в реальном времени и визуальное программирование бортовых систем на основе Makeblock mBlock (Blockly Zelos).

## Основные возможности

- **Управление задачами** — доска (Канбан) и таблица по подсистемам (`OBC`, `EPS`, `ADCS`, `COMMS`, `PAYLOAD`, `GROUND`) с фильтрацией, поиском и привязкой задач к бортовым программам и каналам обсуждения.
- **mBlock Борт ПО** — визуальный конструктор на базе `blockly` (`zelos` renderer) с блоками бортовых подсистем кубсата:
  - **Онлайн-стенд** — симулятор кубсата 1U (баланс энергии EPS, тень Земли, гироскоп и демпфирование B-dot ADCS, радиокоманды UHF 435.800 МГц, журнал UART/AX.25).
  - **Код Python / C++** — трансляция визуальных блоков в MicroPython (`CyberPi / ESP32`) и Arduino / STM32 C++ с экспортом в `.py` / `.ino`.
  - **История версий** — сохранение итераций программы, добавление инженерных заметок к каждой версии и загрузка предыдущих снимков в редактор.
- **Техчат команды** — тематические каналы подсистем через WebSocket со списком участников онлайн, ссылками на задачи, программы mBlock и фрагментами кода.
- **Стенд 1U** — сводка архитектуры подсистем, аппаратных шин и прогресса разработки.

## Запуск

```bash
pnpm install
pnpm dev
```

Сервер запускается на `http://localhost:3000`. Для production-сборки:

```bash
pnpm build
pnpm start
```
